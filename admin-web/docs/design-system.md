# Design System

## Direção visual

Tema claro, corporativo e focado em legibilidade para operação B2B. O layout evita excesso de cartões decorativos e prioriza navegação consistente, tabelas claras e painéis densos o bastante para uso diário.

## Paleta

- Roxo principal: `#6D3DF5`
- Roxo claro: `#F2EDFF`
- Fundo: `#F8F9FC`
- Superfície: `#FFFFFF`
- Texto principal: `#171A24`
- Texto secundário: `#667085`
- Borda: `#E4E7EC`
- Verde: `#16A34A`
- Amarelo: `#D97706`
- Vermelho: `#DC2626`
- Azul MCP: `#2563EB`

## Componentes

- Sidebar fixa com colapso no desktop e drawer no mobile.
- Botões com ícones Lucide.
- Badges por status, prioridade e tipo.
- Cards com raio de 8px.
- Inputs com foco visível roxo.
- Tabelas com cabeçalho discreto e linhas escaneáveis.
